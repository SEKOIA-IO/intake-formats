# Office 365

## Description

[Message Trace Fields definition](<https://docs.microsoft.com/en-us/previous-versions/office/developer/o365-enterprise-developers/jj984335(v=office.15)?redirectedfrom=MSDN>)

The `o365` format now parses Microsoft 365 Copilot audit events from the Office 365 Management Activity API (`Audit.General`) when `RecordType` is `261` and `Operation` is `CopilotInteraction`.
