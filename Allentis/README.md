# Allentis

## Description

Allentis is a French vendor of network monitoring and cybersecurity solutions:
network detection and response (QE-Secure), network TAPs and data diodes (TAPICS),
and network flow and asset analysis (QE-Streams, QE-Flows).

## Intakes

- [QE-Secure](qe-secure): parses the events (alerts, flows, DNS,
  HTTP, TLS, files, SMB, SSH, RDP, anomalies) exported by the QE-Secure NDR probes.
